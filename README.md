## Company Website with Dashboard
Welcome to the repository for our a Laravel Company Website with Admin Dashboard! This project features a two-page website: one for visitors and one for administrators. The visitor page offers essential company information and services, while the admin dashboard provides robust management tools.


## Features
### Visitor Page
- **Home:** A welcoming landing page introducing the company.
- **About:** Detailed information about the company’s mission, history, and team.
- **Service:** A comprehensive list of services offered by the company.
- **Contact:** An interactive contact form and company contact information.

### Admin Dashboard
- **Sidebar Navigation:** Easy access to various management tools.
- **Services:** Manage and update the list of services offered.
- **Testimonials:** Add and manage client testimonials.
- **Features:** Update and highlight key features of the company.
- **Clients:** Manage client information and showcase key clients.
- **Team:** Manage team member profiles and roles.
- **Messages:** View and manage messages received from the contact form.
- **Subscribers:** Manage newsletter subscribers.
- **Settings:** Configure website settings and preferences.

## Setup


- To run this project locally, follow these steps:

1. Clone the Repository:
    git clone https://github.com/lotfy5o/CompanyProject

2. Navigate to the Project Directory:
    cd your_blog_project

3. Install Dependencies:
    composer install

4. Setup Environment:
    - Copy .env.example to .env.
    - Configure your database connection details in the .env file.

5. Generate Application Key:
    php artisan key:generate

6. Run Migrations and Seed Database:
    php artisan migrate --seed

7. Serve the Application:
    php artisan serve
